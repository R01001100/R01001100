### [Lab 1 — Version Control Systems: Git and GitHub](https://github.com/R01001100/Lab1_Git_Laude)

> Introduction to version control using Git, a tool used for tracking changes in projects and managing collaboration among developers. It covers basic Git commands, setting up repositories, saving project changes through commits, creating and managing branches, and working with remote repositories using GitHub for collaboration and project sharing.

`Git` · `GitHub` · `Version Control`

### [Lab 2 — Python Fundamentals: Computational Logic & Control Flow](https://github.com/R01001100/Lab2_Fundamentals)

> Introduction to foundational Python programming concepts. It covers different data types, ASCII conversion, string manipulation, conditional statements, exception handling, loops, and basic forensic hash calculation techniques used for data verification and integrity checking.

`Python` · `Fundamentals`

### [Lab 3 — Functions and Modules](https://github.com/R01001100/Lab3_Functions_Recursion)

> Introduction to functions, scope, recursion, and decorators in Python. Covers function definition, LEGB scope, parametric processing, recursion, decorators, lambda functions, and generators.

`Python` · `Functions` · `Recursion`

`Python` · `Data Structures`

## Final Project — Engineering Data Systems Pipeline

### [EDS_4764_Laude](https://github.com/R01001100/EDS_4764_Laude)

> The final project integrates all lab skills into a **production-level Python data analytics pipeline** built on a real-world engineering dataset from Kaggle. Each student is assigned a unique engineering pillar and research topic based on their student number and surname.

> 🧪 *Built on concepts from Lab 6 (Numerical & Data Analysis), Lab 7 (Data Visualization), and Lab 8 (Object-Oriented Programming).*

### [Laude_4764_IEEE_Paper](https://drive.google.com/file/d/1l6MEAVftRMKXM0VDhcMYYM0Q8eiFQJsg/view?usp=sharing)

> A completed IEEE-structured research paper documenting the design, development, and evaluation of an automated Python data pipeline for solar power telemetry analysis. Covers cloud cover interference detection using NumPy-based statistical computations (mean, median, standard deviation, variance, Pearson correlation), a Random Forest classifier achieving 96.79% accuracy using only temperature and DC power features, and an automated visualization suite with five static plots and two animated sequences. 

`Python` · `NumPy` · `Pandas` · `Matplotlib` · `Plotly` · `OOP` · `IEEE Paper` · `Kaggle` · `Machine Learning`

---

### [Filter Logic](https://github.com/R01001100/EDS_4764_Laude/tree/filter-logic)

> This notebook (FilterLogic.ipynb) explains the data filtering and preprocessing stages of the pipeline in clear and organized steps. It demonstrates how the raw Kaggle dataset — containing 68,778 generation records and 3,182 weather records — is filtered and refined into the 621 clean telemetry records used for the final analysis.

### [Results](https://github.com/R01001100/EDS_4764_Laude/tree/results)

> This branch contains two notebooks that isolate and display the outputs of the pipeline. Covers Tables.ipynb which reproduces all statistical tables from the analysis, and Plots.ipynb which reproduces all static plots and animated visualizations. Both notebooks load from dataset_cleaned.csv (already produced by the main pipeline) and show exactly how each result is computed and rendered.

`Python` · `NumPy` · `Pandas` · `Matplotlib` · `Plotly`

> ⚠️ **Note:** The `filter-logic` and `results` branches are not separate implementations. They are visual walkthroughs created to demonstrate specific stages of the main pipeline — showing how the filter logic is applied and how the results are produced. The actual working code lives entirely in the `main` branch.
